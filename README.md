# Desafio: Consulta de Assentos em uma Sala 

## Objetivo
Desenvolver uma solução em PHP utilizando arrays bidimensionais e funções. A solução simula uma sala com assentos, onde cada posição da matriz representa um assento.

## Tecnologias Utilizadas
1. PHP 8.5.7

## Como Executar
1. Clone este repositório ou baixe o arquivo 'desafio-php-2'.
2. Coloque o arquivo dentro do diretório público do seu servidor local.
3. Inicie o seu servidor local.
